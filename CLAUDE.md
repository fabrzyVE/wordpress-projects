# Trueline Calculator Pages Wordpress

Goal is to create LPagery template that matches the figma design within the figma directory. It needs to be reusable and follow the deisgn of the figma pixel perfect.NOTE : one figma design will be postfixed with "-hubspot" this one means that the form within the design is supposed to be a hubspot form if possible. 

## Resources

- /figma directory 
- .env file with wordpress information
- /images directory for any images needed 

## Related Plugins

- CPT UI
- LPagery Pro 
- HubSpot 

## Workflow

- Create Custom Post Type "Calculator Pages"
- Register LPagery Template for new CPT
- Template must match figma design
- Make sure form data connects to hubspot correctly
- Provide templated variables for the copy as best as you can
